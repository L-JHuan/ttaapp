# 数据需求

运行 TAP-SID 需要两张 CSV 表。

## 1. 用户行为表 `events.csv`

一行表示用户访问一次 POI：

| 字段 | 必需 | 含义 |
|---|---:|---|
| `user_id` | 是 | 稳定的匿名用户 ID |
| `poi_id` | 是 | 与 POI 表一致的匿名 POI ID |
| `timestamp` | 是 | 访问发生时间，格式需统一 |
| `timezone_offset_minutes` | 否 | 当地时间相对 UTC 的分钟偏移；整份数据一致时可在配置中统一给出 |

首轮实验只使用一种能够代表真实访问的行为，不混合点击、曝光等不同语义的事件。

## 2. POI 元数据表 `pois.csv`

| 字段 | 必需 | 含义 |
|---|---:|---|
| `poi_id` | 是 | 唯一且与行为表一致 |
| `latitude` | 是 | POI 纬度 |
| `longitude` | 是 | POI 经度 |
| `category_l1` | 是 | 粗粒度类别 |
| `category_l2` | 是 | 细粒度类别 |

所有坐标必须使用同一种坐标系。公开实验建议统一转换为 WGS84。每个 L2 类别只能
属于一个 L1 类别。类别数量不固定，代码会根据数据中实际出现的类别自动编号。
